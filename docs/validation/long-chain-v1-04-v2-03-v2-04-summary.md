- 一期 04：日志续读在连续滚动时同一页请求多次；获取确认框沿用旧的 refs；预制的文件历史漏掉解决冲突的合并提交（改为 `--diff-merges=first-parent`）；分支栏布局重叠。

## 与参考图和技术方案的差异（汇总，详见各阶段报告）

- 日志页为三栏（分支 / 提交图与列表 / 详情），比参考图示意更完整；比较与文件历史入口为右键与“历史”按钮。
- 分支弹层只分“本地 / 远端”两组，不记录“最近”；Stash 页选中即列出文件；“只储藏选中的文件”沿用 V2-02 的 Ctrl / Shift 多选，不设复选框。
- 标题栏“同步 ▾”统一获取 / 拉取 / 推送（一期 04 的“获取…”已移入）；没有“提交并推送”组合操作。
- 命令模板在技术方案基础上增加：fetch `--no-auto-maintenance --no-write-commit-graph`；switch `--no-guess`；branch `--no-track`；pull / merge `--no-autostash`；push 显式 refspec 与 `--no-follow-tags --recurse-submodules=no`；merge 按核对过的 OID 执行；pop = 按 OID apply 后核对再 drop；不带路径的 stash 命令不设字面量路径。
