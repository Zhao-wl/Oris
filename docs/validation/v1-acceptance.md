# V1 验收与性能计划

状态：验收计划，不是测试结果。日期：2026-09-22。

## 1. 测试层次

1. Git 适配集成测试：使用隔离的真实临时仓库生成工作区、index、commits、refs；由 Git 输出与内容断言核对来源。
2. Diff 组件测试：双端内容 → 同一 DiffDocument → 高亮/统计/导航；重点验证不等长块、Unicode、折叠、换行和空白规则。
3. 桌面主链路：真正启动 Tauri，在 WebView2 与 WKWebView 分别打开仓库并操作，核对用户看到的端点/内容/状态。
4. 性能与发布：固定数据、硬件、构建模式与测量方法，使用 release 构建和安装包；独立于视觉截图。

不为所有内部函数机械补单元测试。围绕 Git 语义、只读边界、旧请求污染、核心阅读及平台行为选择必要测试。

## 3. 最小真实仓库夹具

- Git 实际生成：线性提交、分叉后合并、根提交、空仓库、upstream 存在/不存在/gone、remote-only 提交。
- 文件实际生成：同文件 staged+unstaged、untracked、删除、跨目录 rename、冲突、无末尾换行、CRLF/LF、中文/特殊字符、二进制、图片、LFS 指针和 submodule gitlink。
- 网络场景先用本地 bare remote 确定 fetch 语义；再用已授权测试远端核对既有认证环境。不能把本地 fetch 成功当成 HTTPS/SSH 全部认证已验证。
- 普通读取的前后比较覆盖工作区内容、index、refs、仓库配置和新增文件；应考虑 Git worktree 的独立 gitDir/commonDir。不要在用户真实工作仓库制造测试变更。
- 安全用例用可观察的无害标记脚本证明外部工具没有执行；不能只检查 UI 按钮不存在。

## 4. 性能场景与初始预算

以下是用于启动验证的工程目标，非已测结果/用户承诺。任务 01 必须在测量前记录采用的预算、机器和版本；调整需注明依据，任务 05 不得事后降低门槛来宣称通过。

参考机器：Windows 11 x64、16 GB 内存、SSD；macOS 14+、M1、8 GB 内存、SSD。记录 CPU、内存、磁盘、系统、Git、WebView、应用版本。

| 数据集 | 内容 |
| --- | --- |
| S 常用 | 5 个登记项目；当前仓库 10,000 tracked 文件、20,000 提交、100 个变化文件；常用文本 ≤1 MiB/20,000 行 |
| L 压力 | 100,000 tracked 文件、100,000 提交、2,000 个变化文件；大型生成文本/单超长行；超大图片 |

| 指标 | S 初始工程目标 | 边界 |
| --- | --- | --- |
| 热项目切换到可交互视图 | P95 ≤200 ms | 已加载摘要；新鲜数据刷新另记，不伪装为已完成 |
| 已缓存 diff 文件切换 | P95 ≤200 ms | 包括文本显示，不仅测点击响应 |
| 未缓存常用文件 diff | P95 ≤1,000 ms | 包括 Git 读取、传输、计算与首屏可读 |
| 首次打开本地仓库到可用文件列表 | P95 ≤3 s | release 构建，明确应用冷/热启动与 OS 缓存状态 |
| 典型 diff 滚动 | P95 帧间隔 ≤33 ms | 连续滚动至少 10 秒，记录长帧，不能只测空页面 |
| 5 项目热切换后的进程树内存 | 稳态参考目标 ≤400 MiB | 总进程树、同平台同口径；记录峰值与释放趋势，不只看主进程 |

每个响应场景至少 30 次，报告 P50/P95 与原始记录；启动/外部认证等慢场景单独分类。L 数据集要求有界加载、可取消、不崩溃、不出现无限增长缓存；实际时延和内存上限在任务 01 的压力探测后固定。性能失败不能通过隐藏结果/跳过真实计算解决。

初始内容保护预算建议：常规全文 diff ≤5 MiB 且 ≤100,000 行；单行超过 100,000 字符进入明确降级；图片解码 ≤40 MP。它们是可校准工程默认值，不是宣称能支持的最大值。超预算内容必须有可见状态而非无差异；若用户需要更大范围，另行调整预算并复测。

## 5. 双平台发布验收

- macOS 最低版本 14 的 M1 机器/等效真机环境验证；另在发布时选定的较新受支持 macOS 版本 smoke，记录具体版本。
- Windows 11 x64 真机验证 WebView2、Git for Windows 路径、中文与空格路径。
- 两端从 GUI 正常启动，不能仅在已有开发 PATH 的终端里启动；手动指定 Git 和缺 Git 路径都覆盖。
- 分别测试安装、启动、退出、重新打开及卸载不会删除用户仓库；应用数据是否保留在发行说明中说明。
- 正式发布证据包含 Windows 签名、macOS 签名/公证状态。无账号或证书时明确记阻塞，不绕过系统保护来宣称通过。
