# Issue 38：输入与选择界面反馈修正

2026-10-09，按用户最新七条反馈实施；本轮提交候选分页要求覆盖早期连续滚动方案。

## 改动

1. AI 对话、辅助选择、提交信息生成使用同一个 `AiInputFrame`：左侧蓝色 AI 图标，右侧发送箭头；处理中显示同一转圈样式，可取消的入口在同一位置显示停止动作。保留各入口既有键盘及取消行为。设置页的提示词编辑和路由预览属于配置，不增加即时模型发送动作。
2. 删除选择器底部常驻的预算／实现说明和“仅调整选择”等冗余文字。完成后仅显示增删数量，具体依据通过信息图标悬停查看；真实错误仍显示，提交整文件的必要语义保留。
3. 变更区与附件选择器共用平铺／树状显示切换控件。附件树复用变更区目录构建函数，按嵌套层级展示；平铺显示完整相对路径。
4. 左侧始终只显示未加入对象，删除“仅未加入”复选框；加入后移至右侧，移除后恢复左侧。AI 的候选范围仍包含当前筛选范围内的已加入项，保证“移除某类文件”有效。
5. 提交候选改为上一页／下一页，不再通过滚动加载。每页条数按窗口高度调整，行高仍为 28px；翻页不清空已加入集合。批量“加入全部匹配”仍作用于全部筛选结果。未知总页数不虚构统计。
6. 主界面只保留一个日期区间按钮；弹窗中选择开始／结束日期、校验顺序、应用或清除。取消及 Escape 不提交草稿。
7. 作者和涉及路径共用一个搜索框，通过下拉切换类型。切换清空上一类型条件，防止隐藏条件继续生效；提交关键词／OID 保持独立。
