# 大变更集性能基线

实测使用 Oris 1.0.12 的源码提交 `8d1982ff89c6dba1908083d16c9d16ba2097fe80`。合并后的 `70f4bd5` 与它的 Git 树相同，可以用来复现。测试构建保留桌面 Git 后端并使用独立标识 `com.oris.viewer.perf`，关闭更新检查端点，主窗口不可聚焦。

## 测量口径

- 每个规模创建独立 Git 仓库，工作区有 100、1,000 或 5,000 个未暂存文件，均分到两个目录。使用平铺视图，WebView2 视口为 1440 × 900。每个交互取 30 个样本，P95 采用最近秩。
- 筛选从输入事件开始，到未暂存计数和已渲染列表行符合所筛目录，再等待一帧。两组目录交替筛选，计时内包含 React 更新与列表渲染。
- 冷切换从点击非相邻、此前未打开的文件开始，到 diff 中出现该文件的内容，再等待一帧。避开邻行预取，系统文件缓存保持正常运行状态。虚拟列表滚动到目标行在计时前完成。
- 每轮预读列表首个文件，从点击暂存到操作成功、下一文件的 diff 可读，再等待一帧。逐轮读取真实 Git 索引验证目标文件入库，取消暂存并复核复位。索引断言和复位耗时在计时外。
- 历史大 diff 使用约 10,000 行的旧夹具。两个文件预读后交替切换，统计目标大文件的可读延迟。用 [历史调研](../research/10-diff-scan-limit.md) 的已缓存切换预算 100 ms 对照。

## 2026-11-24 正式结果

北京时间 21:11 开始。Windows 11 build 22631，Intel Core i7-11700（16 逻辑处理器）、47.7 GiB 内存、WebView2 158.0.4370.33、Git 2.44.0.windows.1、Node.js 22.18.0。测试包 SHA-256 为 `980070B3D878645879914CCEC261F6386FB7F34D0AF1A770504B59276F90820B`。

| 变更文件数 | 筛选 P50 / P95（ms） | 冷切换 P50 / P95（ms） | 暂存到下一文件 P50 / P95（ms） | 系统 CPU 均值 |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 19.1 / 30.8 | 28.2 / 154.6 | 364.8 / 850.0 | 26.8% |
| 1,000 | 81.7 / 123.2 | 34.1 / 46.2 | 139.8 / 527.9 | 27.8% |
| 5,000 | 17.9 / 35.8 | 36.2 / 57.0 | 242.0 / 292.3 | 26.1% |

历史大 diff 核对为 1,813 块，已缓存切换 P50 为 79.6 ms，P95 为 148.2 ms，比 100 ms 预算高 48.2 ms。该场景的系统 CPU 均值为 17.4%。每个指标均有 30 个有效样本，无失败，专用进程和临时夹具均已清理。

采样期间同机有其他进程。100 文件组的暂存和冷切换出现较长尾延迟，单轮基线无法归因。1,000 文件筛选后剩 500 行，仍走普通列表，5,000 文件筛选后走虚拟列表，两个耗时不能按文件数线性外推。早期探索轮次曾先暂存第一项、取消暂存，再暂存第二项。第二项确实进入索引，但阅读位置回到第一项。这些探索轮次未计入表内，正式结果只覆盖从首项暂存到第二项。

## 复现

在 PowerShell 中准备项目锁文件对应的依赖和 Windows MSVC Rust 工具链，再执行：

```powershell
./scripts/perf/build-change-set-test.ps1 -SourceCommit 70f4bd5 -OutputDirectory artifacts/issue-43-test
node scripts/perf/change-set-baseline.mjs --manifest artifacts/issue-43-test/test-build.json --output artifacts/issue-43-result.json
```

运行器核对专用构建清单及二进制 SHA-256，启动前检查端口，连接前核对 PID、完整可执行路径、启动时间、Oris 主窗口句柄和端口归属。交互通过本轮 WebView2 的 CDP 连接。旧 `focus-task02-window.ps1` 及其任务 02 调用方保持禁用，运行器没有调用原生显示或激活接口。每组都有独立的夹具、WebView2 配置和应用数据；清理时复核本轮进程的路径、启动时间、调试端口及配置目录。覆盖范围为 Windows 原生应用及 Git 操作的非焦点交互。真实 Windows 前后台焦点切换未测。

正式采样后，使用最终的回环端口和 CDP 清理校验，再以 `--file-view tree --samples 1` 跑通四组冒烟并完成清理。树形冒烟用于校验脚本操作，表中数据仍来自正式的平铺采样。
