# Oris 0.9.1 更新日志

修复并排视图开启“对齐变化”后的滚动与底部对齐问题。

- 修复左侧滚动偶尔卡住、被另一侧同步事件拉回的问题。
- 修复右侧滚动时左侧占位反复重建、内容闪烁的问题。
- 修复滚到底部后代码、差异色块和连接带不齐的问题，包含空行处的新增 / 删除、末尾新增和无末尾换行的情况。
- 保持搜索、行跳转、差异导航、自动换行和块标题下的同步滚动。

用户已验收 Windows 本地修订包。前端回归 454 项通过、1 项跳过；实际反馈文件与合成夹具共 64 个浏览器状态通过，开启对齐的状态中文字和色块边界误差均为 0 px。

本版沿用 Windows x64 和 macOS 14 及以上 Apple Silicon 的安装包与签名自动更新。应用签名与平台支持范围延续 0.9.0。

GUI 回归使用无界面浏览器；旧抢焦点入口保持禁用，没有操作其他应用窗口。真实 Windows 前后台焦点切换、安装 / 卸载及自动更新安装重启链路本轮未执行。
