## 范围

- 按验收计划复核全部需求组与 A01–A15，修复实际缺陷，避免追加产品能力。
- S/L 数据集 release 实测：冷/热打开、项目/文件切换、历史加载、滚动、进程树内存、长时间切换后的增长趋势。
- 优化真实瓶颈：并发/取消、过期结果、按需读取/语法加载、虚拟列表、缓存淘汰；不先重构为大型调度系统。
- 固定 Win11 x64、macOS 14+ arm64（M1 起）发布目标；无 Intel/Universal/Windows ARM64 原生包。
- 系统 Git GUI 启动发现、手动路径、缺失/不支持版本提示；不自动安装开发工具，不打包 Git。
- Windows 安装器/WebView2 依赖；macOS DMG；正式签名/公证链路、依赖许可证说明、版本和校验信息。
- 最小运行与发行说明：支持平台/Git 基线、只读和 fetch 例外、内容预算、已知限制、安装卸载、无自动更新。
