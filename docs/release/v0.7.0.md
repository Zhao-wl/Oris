# Oris 0.7.0 更新日志

Oris 0.7.0 主要改进文件切换和工作区打开性能，并修复重新添加项目、空仓库及空比较范围的状态显示问题。

## 性能改进

- 修复长时间使用后切换文件越来越慢的问题：阅读器固定主题现在只创建一次，避免样式规则随文件切换持续累积。
- 加快大文件切回：减少重复的编辑器配置、事务派发与布局计算，并优化概览轨道标记更新；10,000 行、1,813 个差异块的文件，已缓存切换 P95 从约 108–126 ms 降至约 90 ms。
- 加快工作区打开和成员切换：减少成员发现中的 Git 调用，避免重复扫描；8 个成员的工作区相对普通项目的打开额外耗时从约 370–460 ms 降至约 150–166 ms，首次切到成员从约 0.9 s 降至约 0.3–0.36 s。

## 修复

- 读取真实仓库时显示加载指示；读取完成且没有变化时，明确显示“当前比较范围没有变化”。
- 修复切换到空比较范围或缓存中的空项目后仍显示读取中，以及旧的异步结果影响当前界面的问题。

- 添加项目失败后再次添加时，立即清除上一次的失败说明，避免错误提示一直残留到成员发现结束。

## 平台与验证范围

- 本次提供 Windows x64 安装包和自动更新签名。
- 性能数字来自 Windows 上同机测量，具体时延会随仓库规模、硬件和系统负载变化。
- macOS 最终版本、真实 Windows 前后台焦点切换和 AI 真实模型兼容性仍未完成验证。

本次同版本补入加载状态修复并重新构建。此前已安装 0.7.0 的用户需要手动安装新版安装包；同版本不会再次触发自动更新。
