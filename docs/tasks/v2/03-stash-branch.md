## 用户闭环

作为用户，我手头的改动还没做完时可以先 stash，切到另一个分支处理问题，处理完切回来再恢复 stash；我可以新建、重命名、删除本地分支，也可以检出某个历史提交查看。

## 范围

- **R-STASH**：保存（说明、是否包含未跟踪、只 stash 选中文件）、列表、查看（复用 diff 阅读器，包括未跟踪部分）、apply/pop/drop、操作前核对 stash 身份、冲突时保留 stash。
- **R-BRANCHOP**：分支切换弹层；新建（指定起点、是否立即切换）；切换本地分支；远端分支建立跟踪；detached 检出与“从这里新建分支”；“stash 后切换”；重命名；删除（未合并时强确认）；设置上游。
- Git Log 区的提交右键菜单加入“检出”“从这里新建分支”；stash 页签。
