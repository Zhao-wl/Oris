## 必须保留的关系

1. 项目切换位于应用顶部；打开项目标签与项目搜索入口形成低成本切换路径。项目标签约 160px（实现 164px），名称和长路径省略显示，路径保留完整 tooltip；双击名称或 F2 原位编辑，Enter/失焦确认、Esc 取消、空白回退仓库名。移除独立重命名按钮、固定入口及星标；保留独立拖动柄与持久顺序，编辑时不拖动。移除入口为 ×，仅 hover/当前选中/focus-within 时可见且可点，隐藏时不接受点击；键盘聚焦后可到达该入口。
2. 左侧为工作区/暂存区及文件树；主体为大面积 diff；底部为可收起的 Git Log。
3. diff 顶部提供前后差异、并排/统一、空白规则、词/行高亮及上下文展开；左右比较端点持续可见。
4. 修改蓝色、新增绿色、删除灰色；块内用更强高亮指出词级变化。保留变更类型文本/符号，不能只依赖颜色。
5. 中央连接区表达左右变化块关系；不能出现 Apply/Accept/Revert 等写入箭头。
6. 文件或提交选择联动到同一 diff 阅读器；项目切换保留各项目的选择和阅读位置。
7. 当前实际工作分支、正在浏览的分支、比较端点分别表达；点击分支仅筛选历史，不 checkout。
8. 提供专注 diff、浅色/深色、可调字号、键盘操作；Windows 使用 Ctrl，macOS 采用相应 Cmd 习惯。
9. 并排 Diff 保留“对齐变化”能力但默认关闭；“折叠上下文”也默认关闭，自动换行沿用默认关闭。三个按钮仅显示名称；开启态使用持续的背景、边框和文字色，不能依赖 hover/focus，也不显示圆圈、勾或“已开启/已关闭”附加文字。
10. 文件区默认平铺，一行一个变化文件并显示仓库根相对路径；以单个“当前模式图标 + 下拉箭头”选择平铺/树视图，tooltip/ARIA 解释图标，切换不重置当前 Diff。文件列表独立滚动，标题、过滤和计数固定可见。
11. 并排 Diff 的两侧各有一组镜像外缘轨道：窄差异色标列贴近代码区，较宽滚动条列位于最外缘，两列有明确分隔且不能重叠。色标使用蓝/绿/灰表达修改/新增/删除，thumb 只表达本侧真实 viewport；marker 点击导航，thumb/空轨道/键盘操作本侧并同步另一侧。
12. Diff 阅读配色分四层：蓝/绿/灰块与词级变化保留语义；真实文本选中使用高对比紫色填充；选中内容的其它字面匹配使用青色弱填充/下划线；搜索其它命中与当前命中分别使用黄/橙色。应用内搜索框随深浅主题，提供 Aa、全字、`.*`、计数、前后导航和关闭；差异色标列另以低对比边界带表示本侧逻辑可见行范围，不能用旁边按像素高度计算的 thumb 代替。

## 从效果图补齐的 V1 交互

- 增加“全部本地改动”范围、未跟踪状态、任意两端比较选择器、文件历史入口、图片并排/滑动比较。
- 快照新鲜度仅在有可信依据时显示时间，不能从 UI 刷新时间推断远端更新时间。
- 正式 diff 需支持文本选择/复制、搜索、同步滚动、换行和大内容降级；不能用渲染长字符串模拟完整能力。
- 状态区区分加载中、空结果、失败、内容变化需刷新、超预算；错误明确停止，不默认自动重试。
