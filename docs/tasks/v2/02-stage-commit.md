## 用户闭环

作为用户，我修改代码后，可以在 Oris 中暂存需要的文件、丢弃不要的改动（误操作可以撤销）、写好提交信息并提交；提交信息写错时可以 amend，提交早了可以撤销。

## 范围

- **写操作基础设施**：写通道、OperationRunner（仓库写锁、确认分级、watcher 屏蔽窗口、按影响维度精确刷新、取消进程树、结果与输出展示、外部锁提示）、写操作后的 stat 缓存回写、“快照校验前禁写”接入。
- **R-STAGE 文件级**：stage、unstage、多选、乐观更新与回滚、空 HEAD。
- **R-DISCARD 文件级**：三种丢弃情形、备份与撤销丢弃、备份预算、gitlink 禁用。
- **R-COMMIT**：提交面板与按项目保存的草稿、commit、amend、撤销最近提交、已推送保护、hooks 输出与取消。
- 冲突文件的“标记已解决”入口在本任务中实现为普通 stage 的变体（文案与冲突标记检查），完整合并流程在 V2-04。
