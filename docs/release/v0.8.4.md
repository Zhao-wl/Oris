# Oris 0.8.4 更新日志

Oris 0.8.4 现提供 Windows x64 与 macOS Apple Silicon 安装包。

- Windows x64：补齐 0.8.4 NSIS 安装包、自动更新签名与更新清单，已安装的 Windows 用户可通过应用内更新升级。保留 0.8.2 的 diff 行提交信息、历史定位、变化文件搜索和独立行跳转功能。
- macOS：修复点击“检查更新”时的平台缺失错误，独立检查 GitHub Releases 中对应芯片架构的正式 DMG，不再读取只有 Windows 条目的更新清单。
- macOS 发现新版时，标题栏和设置页提供手动下载入口，并打开该版本的发布页；即使 Windows 的 latest 仍指向旧版本，也能发现 macOS 新版。
- macOS 更新说明明确使用手动安装包。网络异常或 GitHub API 限流仍会报告检查失败，不会误报“已是最新”；本版未消除共享网络出口的 API 限流限制。
- 包含 0.8.3 的 macOS 本机 Codex CLI 检测修复。

Windows 安装包按当前用户安装，具备 Tauri 自动更新签名，尚无 Authenticode 代码签名。

macOS 支持 macOS 14 及以上、Apple Silicon（arm64）。下载 DMG 后退出 Oris，将 Oris.app 拖入“应用程序”替换旧版。0.8.2 / 0.8.3 macOS 用户需要手动安装一次本版，之后应用内才能使用修复后的检查逻辑。macOS 安装包使用 ad-hoc 签名，未使用 Developer ID 签名、未经过 Apple 公证，未提供 macOS 自动更新签名。macOS 的既有核验范围见附件 macos-verification.txt。

本轮 Windows 发布执行前端测试、TypeScript / Vite、desktop release 编译、无 GUI 嵌入资源核验和 NSIS 签名打包。安装 / 卸载、实际自动更新安装、GUI 验收、真实前后台焦点切换及 AI 真实模型调用未在本轮执行。
