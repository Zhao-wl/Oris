# Oris 1.1.0

本版加入内置合并冲突编辑器、JSON/YAML 结构化对比和未读文件跳转，并改善大变更集中的文件列表与 Git 操作反馈。

## 新增

- 在 Oris 中对照 Base、stage 2、stage 3 和工作区结果，逐块采用一侧或两侧，也可手动编辑。保存支持备份与撤销，确认已解决后可继续使用原有的合并流程。 [#56](https://github.com/Zhao-wl/Oris/pull/56)
- JSON 和 YAML 可按字段查看变更，并定位到原始文本行。 [#55](https://github.com/Zhao-wl/Oris/pull/55)
- 可标记当前变更文件已读，并跳转到下一份未读文件。 [#54](https://github.com/Zhao-wl/Oris/pull/54)

## 改进与修复

- 长路径和 Git 错误在紧凑状态栏中展示，完整信息可从详情展开。修正写操作完成后的快照更新，避免旧结果覆盖当前文件或差异。 [#52](https://github.com/Zhao-wl/Oris/pull/52) · [#53](https://github.com/Zhao-wl/Oris/pull/53)
- 复用文件列表的筛选排序与目录树，保留平铺、折叠和 Shift 连选行为。5,000 个变更文件的树形筛选在同机组件测试中，P95 从 5.3 ms 降至 4.0 ms。桌面性能基线覆盖 100、1,000、5,000 文件。 [#57](https://github.com/Zhao-wl/Oris/pull/57) · [#58](https://github.com/Zhao-wl/Oris/pull/58)
- 高级 AI 提示词默认折叠，各项可单独恢复默认。更新 README，新增一键本地 CI。 [#51](https://github.com/Zhao-wl/Oris/pull/51) · [#49](https://github.com/Zhao-wl/Oris/pull/49) · [#50](https://github.com/Zhao-wl/Oris/pull/50)

## 平台与验证

- 发布目标为 Windows x64 和 macOS 14 及以上的 Apple Silicon，自动更新产物使用 Oris 更新签名。macOS 使用 ad-hoc 签名，Windows 安装包未配置 Authenticode。
- 本轮本地前端测试 496 项通过、1 项跳过，工具检查 11 项通过，Rust 冲突测试 12 项通过。真实 Windows 前后台焦点切换、双平台实际安装与自动更新、真实模型和正式代码签名仍待验收。 [#32](https://github.com/Zhao-wl/Oris/issues/32)
