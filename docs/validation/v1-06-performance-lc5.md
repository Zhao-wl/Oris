# 长链 lc5：最终 main 的发布性能测试（Windows）

日期：2026-09-30 至 10-01。任务：[长链 lc5](../tasks/onetime/long-chain-perf-lc5.md) 阶段 2 / 阶段 4。预算依据：[V1 验收计划 §4](v1-acceptance.md)、[V2 验收计划 §3–§4](v2-acceptance.md)（同一场景取较严的一项）、V2-D29（分层内存）、V2-D61（写操作与块操作）。**没有降低或调整任何预算**。上一版：[发布性能测试](v1-06-performance.md)（构建 `ae08225`）、[RC 复测](v1-06-rc-results.md)。

## 结论

- **最终 main（`6de8b52`，构建 `B97C13B8…`）上的完整发布性能会话：22 个套件全部有效（未受干扰），S 数据集的全部时延、写操作、块操作、外观、内存与资源预算，以及 V2-07 工作区 §3 / §4 的全部预算都达标。** 例外只有两类，都与本轮代码无关（**最终 main 为 `59670df`**：之后功能复验又修复了一处添加项目时的界面状态，最终构建 `530D88CE…` 上复测打开与工作区两组，全部达标，见“最终构建复测”）：
  - **未验证**：外部变化 → 界面更新（需要真实前台焦点，AGENTS.md 不允许抢焦点；与上一版相同）。
  - **已知限制（V2-D59，按现状登记）**：强制 Low 级别下“操作结束 3 s”的内存口径 169.4 / 178.1 MiB（≤ 130 / ≤ 140）；“静置 65 s”口径达标（106.7 / 115.2）。
- 达到这个结果之前，在最终构建上发现并修复了 **2 项未达标、1 项余量不足**（技术手段，未改预算与体验）：打开工作区比普通项目多 367 ms（P95 差，预算 ≤ 300）→ 修复后 149 ms；1,813 块的已缓存切换在完整流程中 P95 108–126 ms → 修复后 91.6 ms；其根因之一是**阅读器主题在每次切换文件时重复创建、样式表无限增长**（长时间使用的所有场景都受影响）。见 [lc5 优化结果](perf-optimize-lc5-results.md)“阶段 4 发现并修复的问题”。
- **块操作**：RC 补跑时的 Git 确认 P95 1.22–1.45 s 是负载造成的。本轮低负载下 3 种块操作 P95 为 570–615 ms，同机交替 A/B 中旧构建 `ae08225` 为 584–616 ms，**达标，没有回归**。7 次块操作测量中有 1 次出现 1 次丢弃未执行（见“未复现的失败”）。
- **首次打开**比 RC（332 ms）一度变慢到 567 ms（V2-07 在添加项目时的成员发现），修复后为 P50 382.1 / P95 400.2 ms，首次打开的 Git 进程 13 / 12 个（RC 10 / 9）。
- L 数据集：有界、可取消、不崩溃、内存有界全部满足；100,000 文件的 status P50 147.1 / P95 156.2 ms（V2-D10 的数据，与上一版一致）。
- 阶段 2（2026-09-30 上午）因本机其他会话与程序的持续负载（外部 CPU P95 67–74%）没有得到有效数据，按用户决定跳过；用户清场后（2026-09-30 晚）在阶段 4 完成本报告的测量。阶段 2 的记录见文末。

## 未复现的失败（块操作 A/B 的 B2 轮）

最终构建上共做了 7 次块操作测量（主会话 1 次、A/B 的 B1–B3、加诊断后重跑 3 次）。B2 一轮中第 14 次丢弃（i = 13）在确认后只启动了 2 个 `status`，没有块映射核对与 `apply`。也就是说，操作在执行前的重新扫描处就停止了，这符合 V2-D61 有意保留的“执行前扫描，防止按过期内容写入”。之后脚本按“块数逐次减一”判断，其余 16 次因错位全部判为失败。该轮成功的 13 次 P95 572.9 ms。当时脚本没有记录界面文字；加上失败诊断（状态栏、操作状态、块标题状态）后又重跑 3 次（各 3 × 30 次），**均为 30/30**，未能复现。推测是脚本在上一次丢弃的刷新或文件监听回声尚未完成时点击了下一次，**原因未确认**。旧构建 `ae08225` 的 3 轮没有出现。

## 未验证与已知限制

- **外部变化 → 界面更新（P95 ≤ 1 s）**：需要真实前台焦点（手动步骤见[发布性能测试](v1-06-performance.md)“未验证项”）。
- **失焦后内存的真实焦点切换**：本轮为 `ORIS_WEBVIEW_MEMORY_TARGET=low` 强制级别（V2-D59：静置 65 s 口径达标，操作结束 3 s 口径受 WebView2 回收时机影响）。
- 16 GiB 参考机、冷 OS 文件缓存、macOS：未测。
- 1,813 块文件的滚动帧间隔（研究 10：约 50–60 ms）不在 S 预算内，本轮大文件场景的滚轮帧间隔 P95 为 18.5–19.6 ms（研究 10 的测法不同，见 `p-v2-10-gui.mjs`）。
- 自动更新原地安装、签名：不在本轮范围。
