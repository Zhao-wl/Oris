## 场景与要点

| 场景 | 要点 |
| --- | --- |
| A 日常暂存与提交 | 文件行悬停或选中时，统计数字位置换成 暂存 / 丢弃 按钮；复选框批量操作；侧栏操作条（暂存选中、丢弃选中、储藏）；文件区底部是提交面板（草稿按项目保存、amend 复选、撤销最近提交）；hunk 按钮以紧凑图标浮在每个 hunk 首行右侧；标题栏新增分支按钮与 获取 / 拉取 / 推送（带落后 / 领先数）；去掉“只读”标记 |
| B 分支切换 | 分支弹层：搜索、新建、当前 / 本地 / 远端分组，行悬停操作；Git 拒绝切换时的“stash 后切换”对话框 |
| C 丢弃确认与撤销 | 确认框列出文件并单独标明未跟踪文件会被删除；丢弃后右下角出现“撤销丢弃” |
| D 拉取选项 | 仅快进（默认）/ 合并远端改动；`pull.rebase=true` 时的说明 |
| E 拉取进行中 | 状态栏进度与取消；其他写入口置灰并说明原因；底部“操作输出”页签 |
| F 合并冲突 | 合并进行中横幅；冲突文件分组；一期 03 的只读冲突查看；标记已解决（残留冲突标记时警告）；完成合并 / 中止合并 |
| G 快照校验中 | 标题栏与横幅标“校验中”，写入口不可用；校验完成后提示更新了哪些文件 |
| H 外部 rebase 进行中 | 红色横幅说明不支持，写操作全部禁用，阅读正常 |
| I Stash | 储藏对话框；底部 Git 面板的 Stash 页签（列表 + 内容文件，与一期 04 日志并列） |
| J detached HEAD | 分支按钮警示色、横幅“从这里新建分支”、推送不可用；已推送保护下 amend 与撤销提交不可用 |

## 需要确认的布局选择

1. **同步按钮放在标题栏右侧**（与分支按钮同一行）。备选：放在状态栏。标题栏更显眼，但会挤占标题栏空间。
2. **提交面板固定在文件区底部**，与文件列表共享侧栏高度。备选：独立的可折叠面板或弹窗。固定面板省一次点击，但文件多时列表可视高度变小（计划支持折叠）。
3. **hunk 操作用紧凑图标**（＋ / ↶ / −），悬停出现文字提示，放在 hunk 首行右侧。备选：放在中间连接带里（JetBrains 的做法），但当前连接带只有 26 px 宽，而且 V1 约定连接带不出现写入箭头。
4. **Stash 放在底部 Git 面板的页签里**，与一期 04 的日志并列。备选：放进分支弹层。
5. **操作输出**作为底部面板的页签，状态栏只显示结果摘要，点击展开。
