## 2. 夹具补充

- 本地 bare remote：用于 push/pull 的快进、分叉、被拒绝、上游 gone。
- 可观察的无害 hook 脚本：成功、失败、长时间运行（用于取消）、输出大量内容。
- 进行中状态：由真实 Git 命令生成 merge 冲突、rebase 冲突、cherry-pick 冲突、bisect。
- 外部锁：测试进程持有 `index.lock`。
- 大量写入：在被忽略目录中生成 10,000 个文件，在非忽略目录中生成 200 个文件。
- 全部测试都在临时仓库中进行，不在用户真实仓库中制造改动。

## 3. 性能预算（初始工程目标）

**先测基线**：任务 V2-01 开工前，在当前 main 分支上用相同的方法、数据集、机器测一次，作为 V1 基线。预算在测量前固定，事后不得降低门槛。数据集 S/L、参考机器、release 构建要求与 V1 §4 相同。

| 场景 | 指标 | S 目标 | V1 对照 |
| --- | --- | --- | --- |
| 首次打开 | 到文件列表可交互 | P95 ≤ 1.5 s | ≤ 3 s |
| 再次打开（重启） | 窗口就绪到显示上次快照 | P95 ≤ 300 ms | 无 |
| 再次打开（重启） | 快照校验完成 | 同首次打开 | 无 |
| 热项目切换 | 到可交互视图 | P95 ≤ 100 ms | ≤ 200 ms |
| 后台 dirty 项目切回 | 到显示新鲜数据 | P95 ≤ 800 ms | 无 |
| 切换显示区域 | 到新范围的列表与 diff 可读 | P95 ≤ 50 ms，且不启动 Git 进程 | 无 |
| 已缓存 / 相邻预取的文件切换 | 到文本显示 | P95 ≤ 100 ms | ≤ 200 ms |
| 未缓存常用文件 | 到首屏可读 | P95 ≤ 400 ms | ≤ 1,000 ms |
| 外部变化 | 最后一个文件事件到界面更新 | P95 ≤ 1 s | 无 |
| stage / unstage 单文件 | 乐观反馈 / Git 确认 | ≤ 50 ms / P95 ≤ 500 ms | 无 |
| commit（无 hooks） | 到文件列表与分支状态刷新 | P95 ≤ 1 s | 无 |
| 切换配色方案 / 主题模式 / 字号 | 到界面与 diff 全部更新 | P95 ≤ 100 ms，且不重建编辑器 | 无（V1 为整体重建） |
| 打开设置窗口 | 到可交互 | P95 ≤ 100 ms | 无 |
| 写操作后刷新 | 启动的 Git 进程数 | 只刷新受影响维度；每种操作的进程数上限记录在任务报告中 | 无 |

L 数据集要求：有界加载、可以取消、不崩溃、缓存不无限增长；记录 status 在 100,000 文件下的时延，作为 V2-D10（fsmonitor）的决策依据。

## 4. 内存与资源

| 指标 | 目标 |
| --- | --- |
| 5 项目热切换后的进程树稳态内存 | ≤ 400 MiB（沿用 V1，不放宽），并与 V1 基线对比 |
| 长时间使用 | 连续 200 次项目 / 文件 / 范围混合切换，与第 20 次后的稳态相比增长 ≤ 10%，且没有单调上升趋势 |
| 常驻 Git 子进程 | 空闲状态下 ≤ 5 个；关闭项目后 60 s 内回收 |
| 缓存上限 | BlobCache、DiffCache、快照持久化都不超过技术方案 §7 的上限（通过测试断言，而不是只看代码） |
| 项目数量 | 10 个项目与 5 个项目相比，稳态内存增量主要来自轻量状态（每项目 ≤ 2 MiB 量级） |

统计口径：整个进程树（包括 WebView2 / WKWebView 子进程和 Git 子进程），同一平台同一口径，报告峰值、稳态与释放趋势。

## 5. 合并发布（V2-D19）

- 一期不单独发布。V1 任务 06 作为一二期合并发布验收，复核 V1 A01–A15 与本文 B01–B22，版本必须是最终合并版本。
