# Oris 0.8.2 更新日志

Oris 0.8.2 增加 diff 行提交信息，并改善历史定位与阅读操作。

- 选中 diff 中的一行后，底部显示该行的作者、时间、提交日志与 SHA；悬停显示提交详情和相关变化。浮层在鼠标附近出现，出现后保持位置，内容较长时可在内部滚动。
- 点击作者可在历史中搜索该作者并定位提交；点击 SHA 可直接定位提交，同时自动筛选来源文件。返回来源 diff 可恢复阅读位置与选择。
- 历史的变化文件列表增加醒目的路径搜索框，支持重命名前后的路径；提交搜索和文件搜索均可通过输入框内的 × 清除。
- `Ctrl+G` 改为独立的行跳转面板，颜色跟随主题；`Ctrl+F` 继续用于文本搜索。
- 区分已提交行与本地未提交行，查询失败或内容发生变化时给出提示；浏览行提交信息不修改仓库。

本次提供 Windows x64 NSIS 安装包和自动更新签名，已安装版本可通过应用内更新升级。自动更新签名不代表 Windows Authenticode 代码签名。
