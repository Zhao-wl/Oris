# 变更集 AI 审查（#26，接入已验收 #38）

在 AI 对话输入 `@审查`，可直接用自然语言描述任务。通过输入框的附件入口选择变化文件或提交；文件搜索、批量增删、提交筛选和 AI 辅助选择均复用 #38。无附件时读取未暂存、已暂存及可确定的未推送提交，未推送提交逐页收集到末尾；无法确定上游时明确提示，不把未知当成零条。`@解释` 与审查共用有界原文窗口，主动读取附件正文后解释，无须让模型另行请求展开目录；只输入指令也能直接概括本轮范围。按 #38 最终决定，分支仅筛选提交，不提供分支端点附件；旧 `reviewRequest` 和后端比较接口仅保留兼容能力。

`review.ts` 与 `context-selection/explain.ts` 通过 `context-selection/windows.ts` 先采集预算内的原文快照，再运行模型。快照保存在内存；各文件逐一采集，不宣称整个工作区是同一时刻的原子快照。后端只读读取固定 HEAD/index 对象与工作区字节，差异由已采集的两侧文本计算，不在模型运行中重新读取分页。按预算把多个文件、来源或续页放进同一窗口联合审查。每份来源保留真实路径、左右侧别、端点、比较范围和原文行号；本地同时保留内容身份与定位请求。模型只得到精简原文投影，不发送重复 patch 或内部路径 ID。跨文件问题可提供多处关联原文；主定位和所有关联引用均须通过实际来源与原文校验，任意虚构关联会使该问题标为未核实并禁用定位。

点击问题或关联原文会核验仓库、比较身份、contentId 和原文，再使用现有只读 diff 阅读器跳转原始行。不会将历史提交、暂存区与当前内容合并成虚构版本；同路径、同标题的问题在不同版本下保持独立。

单窗口证据受 8,000 保守 token 估算及路由单次预算共同限制，累计输入/输出计入路由任务预算（默认 96,000），最多 64 次调用。估算按 UTF-8 字节计算，是保守上界，非提供方 tokenizer。预算内的多个文件联合推理；大范围仍需分窗口，不能保证跨全部窗口发现所有关联。未附加依赖、非文本、超长行、底层读取限制及预算未覆盖内容明确显示；不自动扫描或上传全仓库。

内置审查保持 `kind=answer`，源码伪指令和模型操作计划不会触发 Git 写入。取消/关闭在每次读取和模型调用前后检查，迟到响应不能继续下一轮或发布部分结果；项目或分支切换仍停止；分析期间 revision 或内容变化只提示结论基于快照，保留分析结果。定位与写操作继续核验当前版本，过期内容不能直接用于定位或执行。提交组织建议仅引用实际读取的变化文件，保持只读；同文件混合改动需手动整理，不引入 #24/#25 接口。

后端读取沿用 `src-tauri/src/git/ai_review.rs`；模型沿用原路由、`plan_ai_action`、CLI/API 连接与进程隔离。最新验证见 [validation/continuation.md](validation/continuation.md)；原始真实联合模型记录见 [validation/joint-real-model.json](validation/joint-real-model.json)；运行期间主动编辑文件的快照验证见 [validation/snapshot-real-model.json](validation/snapshot-real-model.json)。
