## 交互

diff 工具栏提供“行提交信息”开关，默认开启并保存开关状态。选中行后，底部显示当前侧与行号、最后修改作者、相对时间、提交摘要和 SHA。支持鼠标选行和原生文本选择结束位置；多行选择以结束位置所在行为准。

悬浮详情展示作者姓名与邮箱、精确时间（含时区）、完整提交信息、来源文件和原始行号，并延迟读取该提交相对第一个父节点的真实变化片段。作者与提交者不同时分开展示。浮层每次出现时以鼠标悬停位置定位，靠近视口边缘时翻转或收进视口；一旦显示，就不再随鼠标、聚焦、重复点击、变化片段加载或复制提示移动。增长的内容在视口剩余高度内滚动。关闭后再次出现时重新定位。键盘聚焦时使用触发元素的位置。浮层支持移入、键盘聚焦、复制 SHA、Esc 关闭、点击外部关闭与失焦关闭。

仅通过作者和 SHA 执行历史跳转。摘要打开详情，复制按钮只复制。浮层不提供重复的“定位提交”“查看提交变化”按钮。点击作者用 `<邮箱>` 字面量搜索，避免只按同名姓名筛选；点击 SHA 清除历史筛选，直接选中目标。

定位提交后，右侧变化文件搜索自动带入该行在归属提交中的路径。变化文件搜索带有显式标签、搜索图标、独立背景和更清晰的边框。列表支持按完整路径字面量过滤（忽略大小写，同时匹配重命名前路径），显示匹配数量，可清空并重新输入；只筛选已读取数据，不额外请求 Git。提交 / 比较 / stash 共用该能力。提交搜索与变化文件搜索的清除按钮均位于输入框右侧，使用 ×；不再另设“清除”文字按钮。

目标尚未加载时，后端流式寻找目标在日志中的位置，固定起点 OID，返回目标附近的一页。历史提示当前列表从来源提交附近开始，可继续向更早记录分页；来源提交即使不在当前分支的可达集合中，也作为定位起点保留。用户自己更改分支、搜索或跳到 HEAD 时结束定位模式。

历史中的“返回来源 diff”恢复原筛选、选择、历史模式与列表位置，以及主阅读器的来源文件、版本、显示选项和行选择。若本地仓库版本已变化，重新读取来源文件；文件已移出比较范围时给出提示。

`Ctrl/Cmd+G` 使用独立的行跳转浮层，接管浏览器默认查找快捷键；只有行号、范围提示、跳转和关闭。默认定位当前侧（尚未操作时为右侧），输入正整数并按 Enter，越界则提示；目标位于折叠区段时只展开该区段。浮层和输入框随主题配色，使用独立固定浮层避免阅读区过矮时裁切。`Ctrl/Cmd+F` 保持独立内容搜索，切换到行跳转时收起并清空已有内容搜索。

## 数据边界

- 历史左右侧分别使用固定提交 OID 和对应路径；rename 左侧使用原路径。统一视图删除块及同行删除片段映射到旧文档的真实行号。
- 本地 HEAD 端使用固定 HEAD OID；index / 工作区端把当前阅读器快照作为 `git blame --contents` 输入。临时快照存放在系统临时目录，查询结束自动删除，不修改工作区或 index。
- `--contents` 只能相对当前 HEAD 使用，因此查询前后核验它与阅读快照的 HEAD 一致；变化时报告过期结果。Git 返回的未提交行、未跟踪文件和首次提交前的内容只显示“未提交修改”。
- 行归属表示该行最后一次修改，不等于正在查看的提交，也不代表删除旧行的提交。
- 变化预览来自归属提交和归属时路径，根提交相对空树，合并提交预览明确采用第一个父节点。
- UTF-16、孤立 CR 换行、冲突 stage、非文本 / 降级内容暂不提供归属，显示明确原因。工作区文本端可查询；文件末尾的虚拟空行不查询。
- 浅克隆在详情中标注较早历史可能不完整。重命名遵循 Git blame 的文件重命名跟随；不额外启用跨文件复制追溯、忽略空白或忽略格式化提交。
- 切行查询延迟 160 ms，同一阅读快照最多缓存 128 条结果；异步响应只作用于发起请求的行。归属、预览、历史日志分别使用独立后端代次。

整文件 blame、连续追溯更早修改、跨文件复制来源和额外的 Git 写操作不在本次范围。
