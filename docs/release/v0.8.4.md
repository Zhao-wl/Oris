# Oris 0.8.4 更新日志

Oris 0.8.4 修复 macOS 点击“检查更新”时的平台缺失错误。

- macOS 独立检查 GitHub Releases 中对应芯片架构的正式 DMG，不再读取只有 Windows 条目的更新清单。
- 发现新版时，标题栏和设置页提供手动下载入口，并打开该版本的发布页；即使 Windows 的 latest 仍指向旧版本，也能发现 macOS 新版。
- 更新说明明确 macOS 使用手动安装包。网络异常或 GitHub API 限流仍会报告检查失败，不会误报“已是最新”。

本次仅提供 macOS Apple Silicon（arm64）安装包，支持 macOS 14 及以上。下载 DMG 后退出 Oris，将 Oris.app 拖入“应用程序”替换旧版。0.8.2 / 0.8.3 用户需要手动安装一次本版，之后应用内才能使用修复后的检查逻辑。

安装包使用 ad-hoc 签名，未使用 Developer ID 签名、未经过 Apple 公证；本次为手动安装包，未提供 macOS 自动更新签名。Windows 自动更新仍使用 0.8.2。共享网络出口仍可能触发 GitHub API 限流，本版未消除该限制。

前端 366 项测试、新增更新检查 9 项测试和 macOS desktop 编译通过。后端全量有 8 项既有失败，均已在未修改基线上复现；完整安装 / 卸载、GUI 验收及真实前后台焦点切换未在本轮执行。具体包核验范围见附件 macos-verification.txt。
