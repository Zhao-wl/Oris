# Oris 0.8.3 更新日志

Oris 0.8.3 修复 macOS 上自动检测本机 Codex 工具时的漏检问题。

- 支持新版 ChatGPT / Codex 应用包内的 Codex CLI 路径，包括内嵌的 `CodexCLI.app` 和命令包装目录。
- 从 Finder 启动、未继承终端 PATH 时，也能检测系统或用户“应用程序”目录中的 Codex；保留旧版应用包路径及 PATH 中工具的优先级。

本次仅提供 macOS Apple Silicon（arm64）安装包，支持 macOS 14 及以上。将 DMG 中的 Oris.app 拖入“应用程序”安装。

安装包使用 ad-hoc 签名，未使用 Developer ID 签名、未经过 Apple 公证；本次为手动安装包，未提供 macOS 自动更新签名。Windows 自动更新仍使用 0.8.2。

Codex 检测的后端回归测试和本机 CLI 检测通过；用户已确认修复版界面能检测到 Codex。完整安装流程、AI 真实模型调用和系统前后台焦点切换未在本轮验证。
