## 场景清单

1. 标题栏右侧以“设置”取代原浅 / 深色按钮；点击或按 Ctrl+, / Cmd+, 打开设置窗口，Esc 或右上角 × 关闭。左侧显示“外观”“Git”和灰显的“更多分类（以后）”，右侧显示当前分类。
2. “外观”中可演示浅色、深色、跟随系统；浅色与深色各保留一套所选方案。两个列表显示研究 08 中的方案名、代表色板与高对比标记。切换会立即改变背后的应用主体；阅读界面的结构、选中文件与示例 diff 保持可见。
3. diff 字号滑块为 11–18；Ctrl/Cmd + `=` / `-` / `0` 在本页演示增大、减小、复位，并与滑块同步。旧工具栏不再出现字号控件。
4. P-V2-05 的 A / B / C 方案放在标为“待决策”的比较控件中；小型 diff 预览随选择变化。C 额外显示“跟随主题（红绿）”切换。它是决策演示，不表示已确认把此控件加入产品。
5. “Git”中路径可留空示意自动发现；当前有效设置、实际使用路径、版本和最低版本 2.31.0 持续可见。预设按钮演示校验成功、路径无效、版本过低。失败时状态提示仍使用上一次有效值。效果图不访问文件系统、不执行 Git。
6. 外观与 Git 分类都有旧入口迁移提示，说明路径栏“Git 设置”、diff 工具栏字号滑块和标题栏浅 / 深色按钮的位置变化。整个设置窗口不设“应用 / 确定”按钮。

## 已确认的布局方向

- 设置使用覆盖阅读界面的模态窗口；左侧分类，右侧设置项。
- 浅色与深色方案采用并排、可滚动的列表，显示色板与高对比标记。
- 效果图中的 diff 小预览位于外观页配色决策演示控件下方。最终是否保留该控件，取决于 P-V2-05。
