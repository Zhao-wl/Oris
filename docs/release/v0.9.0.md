# Oris 0.9.0 更新日志

本次发布提供 Windows x64 安装包。

- AI 解释与审查支持固定快照、跨文件联合分析、关联位置校验及原文定位；解释携带原始差异上下文，未推送提交范围覆盖全部相关提交。
- AI 运行期间仓库内容发生变化时，继续分析已选定的快照；共享上下文附件选择统一到输入区，压缩上下文索引，并按需读取附件证据。
- 改进 AI 选择元数据的批量读取、请求耗时展示、选择保留和完成后的命令清理，以及输入区和选择器布局。
- 支持自定义变更文件忽略规则及对应 AI 配置。
- 补齐分支切换验收与旧 GUI 脚本安全清理：六个旧反馈入口仅保留拒绝执行逻辑，原生抢焦点 helper 继续禁用。

已放弃的行级暂存、精细 diff 和代码追溯功能不包含在此版本中。

Windows 安装包按当前用户安装，具备 Tauri 自动更新签名，尚无 Authenticode 代码签名。本次不提供 0.9.0 macOS 安装包，现有 macOS 0.8.4 安装包仍可从历史发布下载。

发布验证覆盖前端回归、后端测试、TypeScript / Vite、Windows desktop release 构建、无 GUI 嵌入资源核验和签名安装包。本轮不执行安装 / 卸载、实际自动更新安装、真实 Windows 焦点切换或 AI 真实模型调用。
