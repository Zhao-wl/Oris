- 按验收计划复核全部需求组与 A01–A15，包含新 03 图片与冲突版本查看，修复实际缺陷，避免追加产品能力。

- Windows 安装器/WebView2 依赖；macOS DMG；正式签名/公证链路、依赖许可证说明、版本和校验信息。
