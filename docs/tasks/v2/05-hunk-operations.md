# V2-05 — hunk 级暂存与丢弃

状态：Pending（未开始）。依赖：V2-02；默认在 V1 05 之后（空白规则会影响 hunk 语义）。

## 用户闭环

作为用户，同一个文件里既有要提交的修复又有临时调试代码时，我可以在 diff 中只暂存修复所在的 hunk，并丢弃调试代码所在的 hunk。

## 范围

- 在 diff 阅读器中逐 hunk 暂存（未暂存范围）、取消暂存（已暂存范围）、丢弃（未暂存范围），并排与统一视图都可用。
- **patch 由 Rust 按原始字节生成**，不使用前端解码后文本上算出的 hunk 边界。执行前先 `git apply --check`；与显示时的 revision 不一致时拒绝执行并刷新。
- 前端显示的 hunk 与 Rust 生成的 patch 之间需要建立一一对应关系；对应不上的 hunk 不显示操作按钮，并说明原因。
- 禁用条件：“全部”范围、忽略空白模式、冲突、二进制、子模块、仅 mode 变化、超出内容预算。
- hunk 丢弃纳入 R-DISCARD 的备份与撤销机制。
- 行级操作不在范围内。
