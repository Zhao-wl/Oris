# 02 — 多项目与完整本地变更浏览

状态：Ready（已获用户批准启动，尚未开始）。依赖：01 Windows 基础覆盖通过；01 的 macOS 真机门禁继续保留，但不再阻断 02 启动。

## 用户闭环

作为用户，我能在多个仓库之间快速切换，准确阅读未暂存/已暂存/全部本地变化，并在外部 Git 操作后继续原阅读位置。

## 范围

- R-PROJECT 全部：添加、去重、同名路径识别、固定/最近、项目搜索/标签切换、移除记录、持久化与合法状态恢复。
- R-LOCAL 全部：三个比较范围、未跟踪、同文件两层变化、删除、rename、初始仓库、冲突明确状态。
- R-FILES：树/列表、完整相对路径平铺与树状结构切换、路径过滤、状态/统计、前后文件导航、复制路径；路径解析使用稳定可逆标识。最新用户反馈已授权提前交付“默认平铺完整相对路径 + 保留树切换”切片；完整前后文件导航、复制路径及多项目状态仍随 02 实施。
- 最近项目恢复：已提前交付“最近一次成功打开的单仓库路径 + 最小必要 Git 路径”恢复切片；失败打开不覆盖成功记录，缺失路径只尝试一次并明确报错。完整最近项目列表、固定/移除、多项目恢复仍未实施。
- 外部工作区/index/refs 变化检测、事件合并、回到前台核对、手动本地刷新；不得调用 fetch。
- 仓库/请求 revision 隔离、取消与过期结果丢弃、有界内容缓存；每项目恢复浏览锚点但不常驻全部编辑器。
- 设置与浏览状态写应用数据目录，不写用户仓库。路径或 ref 失效时明确提示，不做猜测修复。

## 验收

- [ ] A02/A03 全部：5 项目真实切换、重复/同名、移除不删目录、重启恢复；模拟慢 A 请求，B 不被污染。
- [ ] A04：同一文件 staged/unstaged/HEAD 三组内容逐项核对；未跟踪独立，空 HEAD 正确。
- [ ] A05：外部修改、暂存、提交、checkout 后更新；本地刷新不联网。
- [ ] A12 路径部分：中文、空格、特殊字符、不可直接解码路径有明确处理，不通过拼接字符串误取文件。
- [ ] 无变化、筛选无匹配、失败、旧快照、未知项目状态分别表达。
- [ ] Win11/Mac 都验证文件监听和 GUI 启动；性能记录含切换 P50/P95、缓存预算与过期请求行为。

## 交付与排除

多项目本地阅读链路与证据；不提供 Git 写操作、全仓索引或远端后台扫描。主要覆盖 R-PROJECT/R-LOCAL/R-FILES/R-UX 的状态部分，延续 R-SAFE/R-PERF。
