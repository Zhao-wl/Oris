## 待用户决定

以下为长链（一期 05 → V2-05 → 一期 06）实施中按“最保守、可逆”做法先行落地的事项，编号从 V2-D50 起；用户确认前均可改。

- V2-D50（一期 05，空白规则）：选项只有“保留空白 / 忽略空白”，**默认保留**；“忽略空白”与 `git diff -w` 一致（只略去行内空格、制表符的差异，空行的增删仍显示），只影响显示，计数 / 高亮 / 导航来自同一份结果，工具栏常驻“已忽略空白 · 略去 N 处”标记；规则只在本次会话内有效，不持久化。未提供“忽略行尾空白”“忽略空行”等更细的规则。
- V2-D51（一期 05，编码）：只解码 UTF-8（可带 BOM）与带 BOM 的 UTF-16 LE/BE；含 NUL 按二进制；其他字节（GBK、Shift-JIS、Latin-1 等）显示“编码不受支持”并说明原因，不猜测、不用替换字符显示（研究 06 §5）。是否增加手动选择编码的小型白名单，待用户决定。
- V2-D52（一期 05，键盘）：前后差异 F7 / Shift+F7（沿用 JetBrains，Windows 与 macOS 相同）；专注 diff 为 Ctrl/Cmd+Shift+Enter 切换、Esc 退出，隐藏项目栏、路径栏、文件侧栏与底部 Git 区，只在本次会话内有效。
- V2-D54（V2-05，非 UTF-8 的块操作）：编码不受支持的文件默认仍只显示“编码不受支持”；说明卡片提供“按单字节（Latin-1）显示”，用户选择后两侧逐字节显示（多字节字符显示为乱码），差异与块操作按原始字节计算；只在本次会话、该文件当前内容上有效。用于满足 B15“非 UTF-8 内容”的块操作；是否保留这个入口、是否改为手动选择编码，待用户决定。
- V2-D55（V2-05，块映射的读取时机与范围）：块映射（一次只读 `git diff -U0`）只在指针移入 diff 或键盘聚焦时读取，浏览、切换文件与范围不启动 Git 进程（保持 V2-01“切换显示区域不启动 Git 进程”）；在此之前按钮照常显示，点击时先读取并核对。块操作只提供给“已修改”的文本文件：新增、删除、重命名、未跟踪、类型变化、符号链接、子模块、二进制、超出内容预算、仅 mode 变化都给出原因并使用文件级操作。显示的块与 Git 的块按两侧行范围完全相同才对应，对应不上的块不显示按钮。
