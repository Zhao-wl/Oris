## 反馈与实现

| # | 反馈 | 实现 |
| --- | --- | --- |
| 1 | 搜索后没有提交信息 | 原因：搜索结果中的提交彼此多半不相连，拓扑布局为每个缺失的父提交保留一条泳道，图宽随结果数增长，把提交信息挤出可见区域。搜索时改为只列节点、不画连线（`flatLayout`）；另外把图宽上限设为 16 条泳道，提交信息列保留最小宽度 |
| 2 | 左、中、右三栏不能拖动调整 | 两条分隔条可拖动；也可以聚焦后用方向键调整（Shift 加大步长），双击恢复默认宽度。宽度保存在 `localStorage`（`oris.historyColumns.v1`），中间栏至少保留 260 px |
| 3 | 路径超框时应显示末尾，放得下时左对齐（所有路径） | 新增共用组件 `PathText`：外层 `dir="rtl"` 让溢出和省略号落在开头，`text-align:left` 保证放得下时左对齐；内层 `<bdi dir="ltr">` 保持路径字符顺序。已替换：文件列表（平铺路径、目录名、改名前路径）、阅读器标题与改名前路径、状态栏仓库路径、项目标签页路径、确认框中的文件列表、历史页的变化文件 / 改名前路径 / 文件历史、Stash 文件。原先文件列表里用 canvas 测量截断的 `TailPath` 已删除 |
| 4 | 左侧不需要“获取”按钮，改为双击分支切换 | 左侧去掉“获取…”（获取仍在标题栏“同步 ▾”中）。单击仍只筛选历史；双击本地分支切换（走原有的切换流程，包括“stash 后切换”）；双击远端分支建立同名本地跟踪分支并切换（同名本地分支已存在时沿用原有的选择对话框）。当前分支、写操作不可用时双击不执行 |
| 5 | 分支区域支持搜索 | 左侧顶部搜索框，同时匹配本地分支、标签、远端分支和 stash（说明、编号、储藏时所在分支）；搜索时展开全部分组，没有匹配项的分组隐藏；Esc 清空 |
| 6 | 区分本地分支和远端分支 | 本地分支与远端分支分成两组；远端分支再按 remote 分组，组内显示去掉 remote 前缀的名称 |
| 7 | 参考图 2：分支 / 标签 / 远端 / Stash 四类，可折叠；去掉 Stash 页签 | 四个分组（本地分支、标签、远端分支、Stash），每组和每个 remote 子组都可折叠，折叠状态保存在 `localStorage`（`oris.historySidebar.v1`），默认只折叠标签。后端 `read_refs` 增加标签（附注标签解引用到提交；指向树 / blob 或多层嵌套的标签不列出），单击标签筛选历史，右键可设为比较端点。Stash 页签去掉：Stash 分组标题上的“储藏…”在右侧打开储藏表单（说明、包含未跟踪文件、只储藏选中的文件）；单击 stash 在右侧显示内容与“应用 / 弹出 / 删除…”；正在查看的 stash 被弹出或删除后右侧回到提交详情 |
| 8 | 页签改名为“历史” | “日志”改为“历史”；相关提示文字同步修改 |
