# Oris 1.0.0

本次大版本更新重新整理文件审核布局，并修复暂存操作时列表闪烁的问题。

## 文件审核布局

- 精简顶部项目与操作区域，添加项目统一使用“+”，差异阅读区域获得更多可视空间。
- 底部页签调整为“文件、历史”，统一高度，支持拖动调整下方面板高度并记住设置。
- “文件”页同时展示未暂存、已暂存和紧凑提交区；全部暂存与全部取消暂存使用带悬浮说明的图标。
- 文件路径保持单行展示，超长路径可横向滚动查看，避免拆分文件名与目录增加行高。
- 历史默认按约 15% / 50% / 35% 分配分支、提交列表与变更文件区域，保留宽度调整。
- 差异工具栏支持折叠；操作输出移至状态栏详情入口，保留错误诊断和撤销丢弃。

## 修复

- 修复暂存或取消暂存时，轻量快照与统计信息分次刷新造成的列表闪烁。
- 保持未受影响文件行的 DOM 与滚动位置，避免折叠区域出现或消失时重建整个列表。
- 修复跨未暂存、已暂存区域选择文件时比较范围与文件选择的同步。

## 平台

- Windows x64 安装包。
- macOS 14 及以上、Apple Silicon 安装包。
- 双平台签名自动更新包。macOS 使用 ad-hoc 签名，未提供 Apple 公证；Windows 未提供 Authenticode 代码签名。

## 验证范围

本地前端回归 466 项通过、1 项跳过；完成 Windows 本地构建和嵌入资源核验。正式发布由 CI 再次执行双平台测试、构建与更新签名核验。

布局检查采用无头浏览器与 DOM 测试；本轮未执行真实 Windows 前后台焦点切换，也未执行安装及自动更新重启流程。旧抢焦点脚本保持禁用，验证不操作其他应用窗口。
