## 本轮测试与构建

- 前端：`npx vitest run --no-file-parallelism`，44 个文件、345 项测试全部通过。
- 后端：在 0.8.0 上执行 `cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --lib -- --test-threads=2`，190 项通过、0 失败、5 项跳过。跳过项为三个性能探针、指定仓库的只读探针与 40 MP 图片完整解码边界探针，均在测试中显式忽略；本次不宣称重新验证这些探针或性能预算。
- 首次使用不带 `--lib` 的无 desktop 测试命令时，依赖 desktop 的主程序和示例编译失败，随后限定库测试。首轮库测试 189 项通过，AI 取消测试因未在限时内观察到请求到达假服务而失败；单独复测及最终完整复测均通过，不将首轮失败表述为全部通过。
- 版本提升后的首次复测链接遇到 MinGW 原生库的 `nanosleep64` 不匹配；仅为测试进程前置 `D:\Tools\Rust\msys2\msys64\mingw64\bin` 以使用一致工具链后，链接与测试通过。未为此修改产品代码或系统 PATH。
- 正式构建在 PowerShell 中通过 `scripts/publish-release.ps1` 和 `scripts/build-release.ps1` 完成，TypeScript、Vite、desktop release 编译与 NSIS 签名打包通过。第三方许可证与 WebView2Loader 资源按现有脚本打包。
- 无 GUI 的 `verify_release_entry` 验证 production `frontendDist` 为本地目录、custom protocol 启用、主窗口入口为嵌入 `index.html`，共嵌入 26 项资源；入口引用的 JS/CSS 与 diff Worker 检查通过。此项没有创建应用窗口。

本轮未启动 GUI 验证，未修改危险窗口调用。已静态检查 `scripts/focus-task02-window.ps1` 及 `scripts/task02-feedback-*.mjs`：前者直接报错退出，后者通过直接抛错或导入 `task02-gui-disabled.mjs` 停止；未发现可执行的 `SetForegroundWindow`、`ShowWindow` 或 `AppActivate` 调用。本轮只构建和运行无 GUI 测试，不枚举、显示、隐藏、移动或激活任何应用窗口，没有操作 Codex、ChatGPT 或用户已有 Oris 实例。
