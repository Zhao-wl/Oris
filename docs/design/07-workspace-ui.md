## 界面要点

1. **项目栏**：一个工作区只占一个标签，名称前有“工作区”标识，第二行是路径和子模块数。
2. **标题栏**：不加面包屑，也不另加一行。logo 右侧原来显示项目名称的位置，在工作区中改为“当前仓库名称 ▾”（例如 `client ▾`，选中父仓库时为 `game-workspace ▾`），点击即打开仓库选择器；普通项目照旧只显示名称。工作区名称由项目栏的标签和选择器顶部的说明体现。分支按钮、获取 / 拉取 / 推送都跟随当前仓库。
3. **快捷键**：Windows 用 `Ctrl+E`，macOS 用 `⌘E`，打开或关闭仓库选择器。`Ctrl+1`–`9` 已经用于切换项目，所以没有用数字键。选择器内 `↑` `↓` 选择（跳过灰显项）、`Enter` 切换、`Esc` 关闭，输入即搜索名称或路径。
4. **选择器分组**：父仓库 → 子模块（按 `.gitmodules` 顺序，worktree 用 `⤷` 缩进在所属仓库下）→ 手动加入。手动加入的仓库悬停时显示“移出”。
5. **徽标**：
   - 分支或 `detached @ oid`。
   - “偏离记录”（黄）：当前提交与父仓库记录的指针不同。
   - 改动数：“N 个改动”或“无改动”；尚未读取时为“未扫描”，读取中为“读取中…”。
   - “有变化”（虚线）：打开工作区后在外部发生了变化。
   - “未初始化” / “目录缺失”：该行灰显，不能打开。
6. **子模块指针开关**：放在变更列表筛选框右侧，只在含子模块的仓库出现，默认关闭。悬停说明开关的含义和保存方式。
7. **嵌套仓库说明**：放在变更列表底部，可折叠，说明可以写入 `.gitignore`。父仓库中列成员 worktree，提供“切换”；子仓库中列独立嵌套仓库，提供“加入工作区”。
8. **历史联动**：日志中修改了子模块指针的提交带“◫ 子模块指针”标记。提交详情中每个子模块一行，提供“在 X 中比较”。
9. **提示**：并入已有项目、直接添加子模块、加入嵌套仓库、子仓库缺少提交，都用右下角提示，不弹确认框。这些操作都只改应用记录，不写仓库。
