# 02 — 多项目与完整本地变更浏览

状态：Blocked（Windows 实现与基础需求覆盖已通过；双平台最终验收仍等待 macOS 14+ Apple Silicon 上的 GUI、WKWebView 与文件监听真机验证）。依赖：01 Windows 基础覆盖通过；01 的 macOS 真机门禁继续保留。

## 用户闭环

作为用户，我能在多个仓库之间快速切换，准确阅读未暂存/已暂存/全部本地变化，并在外部 Git 操作后继续原阅读位置。

## 范围

- R-PROJECT 全部：添加、去重、同名路径识别、项目搜索/紧凑标签切换、双击名称编辑别名、独立拖动顺序、× 移除记录、持久化与合法状态恢复。用户已取消固定入口和星标，旧 pinned 仅作存储兼容，不影响展示/顺序。
- R-LOCAL 全部：三个比较范围、未跟踪、同文件两层变化、删除、rename、初始仓库、冲突明确状态。
- R-FILES：已交付树/列表、默认平铺完整相对路径与树状结构切换、路径过滤、状态/统计、前后文件导航、复制路径；路径解析使用稳定可逆标识。
- 已保存项目恢复：版本化多项目列表、用户拖动顺序、持久别名、移除记录、每项目阅读锚点与重启恢复；启动自动加载已保存的活动项目，不依赖聚焦或再次点击。失败打开不覆盖成功记录，仓库路径或已选文件失效时明确说明并退回合法入口。
- 外部工作区/index/refs 变化检测、事件合并、回到前台核对、手动本地刷新；不得调用 fetch。
- 仓库/请求 revision 隔离、取消与过期结果丢弃、有界内容缓存；每项目恢复浏览锚点但不常驻全部编辑器。
- 设置与浏览状态写应用数据目录，不写用户仓库。路径或 ref 失效时明确提示，不做猜测修复。

## 验收

- [x] A04 Windows：同一文件 staged/unstaged/HEAD 三组内容逐项核对；未跟踪独立，空 HEAD 正确。
- [x] A05 Windows：外部修改、暂存、提交、checkout 后更新；本地刷新不联网。
- [x] A12 Windows 路径部分：中文、空格、特殊字符、不可直接解码路径有明确处理，不通过拼接字符串误取文件。
- [x] Windows 状态表达：无变化、筛选无匹配、失败、旧快照、未知项目状态分别表达；失效阅读锚点明确提示并回到合法入口。
- [ ] 双平台门禁：Win11 已验证文件监听、GUI 启动、切换 P50/P95、缓存预算与过期请求行为；macOS 14+ Apple Silicon 尚未验证 GUI、WKWebView 与文件监听。
