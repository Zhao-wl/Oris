## 待用户决定

- P-V2-05／P-V2-06／P-V2-07：用户要求先做出一个可切换全部选项的体验版，直观感受后再决定（2026-09-24）。
- P-V2-05：diff 颜色语义。A（推荐）保持 Oris 已确认的“修改蓝、新增绿、删除灰”，色值从方案中取；B 完全采用 VS Code 的“新增绿、删除红”（需推翻 V1 已确认的配色语义）；C 在设置中提供二选一开关。详见[研究 08 §4](../research/08-vscode-color-themes.md)。
- P-V2-06：移植范围。建议首批移植 VS Code 默认主题系列 10 套（Dark/Light 2026、Dark/Light Modern、Dark+/Light+、Dark/Light Visual Studio、两套高对比），其余 9 套第三方来源主题（Monokai、Solarized 等）作为第二批；也可以一次移植全部 19 套。数据成本很低，主要成本是逐套的视觉验收。
- P-V2-07：默认配色。建议保留当前的 Oris 配色（V1 已确认的 JetBrains 风格）作为默认方案，VS Code 方案作为可选项；或者改为以 VS Code 的 Dark 2026 / Light 2026 为默认。
- ~~P-V2-08~~：已关闭，见 V2-D26。原建议：建议放在 V2-01 之后、V2-02 之前：V2-06 会把界面颜色全部收拢为变量，二期后续新增的提交页、同步、横幅等界面可以直接使用，避免再写死颜色；它依赖 V2-01 的前端 store 与单编辑器实例。这会调整 V2-D17 已确认的顺序。
