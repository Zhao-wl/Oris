# Oris 0.8.0 更新日志

Oris 0.8.0 新增 AI 连接测试、可配置的指令与模型路由，以及固定主模型的临时对话，并改进文件差异定位和提交历史布局。

## AI

- 设置 → AI 拆分为“连接与模型”“指令”“规则路由”。新增“测试连接”，通过当前配置发送固定的简短请求，最长等待约 30 秒，不发送项目文件内容；API 使用已保存的密钥。
- 支持新增、编辑、复制、删除和停用指令，配置提示词、所需上下文及“仅回答 / 允许应用操作”模式；提供状态、解释、审查、提交、拉取、合并、历史、设置八条推荐指令。
- 每条 `@指令` 可以绑定独立的 AI 配置与模型；默认对话和已暂存提交信息生成也可单独选择配置。路由预览只解析规则，不调用 AI；指令或目标不可用时明确报错。
- AI 入口改为临时对话窗口，展示输入、回复和应用执行结果，支持基础 Markdown、代码块与复制。首次发送后固定会话主模型及系统提示词；`@指令` 独立调用自己的路由模型，结果回到主会话，后续普通消息继续使用主模型。
- 对话绑定当前项目与分支，关闭后不保留会话；切换项目关闭窗口，分支变化时停止后续请求并提示重新打开。停止或关闭会取消模型请求，已开始的应用操作按原有机制完成。
- 支持以 JSON 导入、导出全部或选中的指令和关联路由。导入可合并或替换，并映射到本机 AI 配置；导出不包含凭据、服务地址、本机程序路径或对话记录。旧 AI 配置与自定义提示词在迁移时保留。
- 仓库上下文按指令读取，执行前仍检查仓库状态与应用权限。“仅回答”模式不执行应用操作；自定义指令不开放任意命令或文件写入。

## 差异阅读与历史

- 首次打开尚无阅读记录的文件时，自动滚动到第一处差异；已有阅读记录时恢复原位置，无差异时保持顶部。自动定位不会抢走文件列表的页面焦点。
- 调整提交历史行布局，改善提交信息、作者、时间与文件路径的排列和截断显示。

## 平台与验证范围

- 本次提供 Windows x64 NSIS 安装包和自动更新签名，0.7.0 用户可通过应用内更新升级。
- 自动更新签名不代表 Windows Authenticode 代码签名。
- macOS 最终版本、真实 Windows 前后台焦点切换和 AI 真实模型兼容性未在本次发布中验证。单元、组件及无 GUI 资源校验的结果记录在发布收尾文档中。
