## 测试与边界

- `npx vitest run --no-file-parallelism`：46 个文件、366 项测试全部通过。
- 后端 `cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --lib -j 2 -- --test-threads=4`：203 项通过、0 失败、5 项原有显式忽略，包含全部 9 项新增更新检查测试；这是不启用 desktop 的后端单元 / 真实临时 Git 仓库测试，不能当作桌面 GUI 验收。
- 后端 debug 测试最初受 Rust 自带 MinGW 链接器与本机 MSYS2 pthread 库版本不一致影响（`nanosleep64` 未解析），改用 MSYS2 `gcc.exe` 及匹配的进程内 PATH。后续一次并发编译出现临时原生库读取 `os error 1006`，降低 Cargo 编译并发至 2 后完成编译。最终完整结果来自 `rust-tests-parallel.log`；中途终止的串行测试日志及失败的编译日志保留，不计为通过。环境调整仅用于补充测试，没有修改仓库工具链配置或正式 Windows 发布构建。
- PowerShell 发布构建完成 TypeScript、Vite、Windows desktop release 编译、第三方许可证清单生成及 NSIS 自动更新签名打包。现有标签已存在，使用 `publish-release.ps1 -DryRun -Version 0.8.4 -NotesFile ...` 构建，再向原 Release 上传 Windows 资产并更新正文、标题和 latest 标记。只有旧的 `latest.json` 被同名替换。
- 无 GUI 的 `verify_release_entry` 通过：custom protocol、本地目录入口、26 项嵌入资源有效，入口 JS 为 `index-CULQZzRI.js`，CSS 为 `index-DllZb4Sq.css`，包含 diff Worker。Vite 单包超过 500 kB 的现有提示仍存在。
- 本轮未复测安装 / 卸载、安装后启动、实际自动更新安装链路、macOS、AI 真实模型或性能预算。
- 本轮未执行 GUI 自动化，未修改或调用 `focus-task02-window.ps1` 及其旧调用方；没有原生显示、隐藏、移动或激活窗口的调用，没有操作其他应用窗口，也未启动可见测试 Oris。真实 Windows 焦点切换已验证范围为空，DOM / CDP 焦点模拟也未执行，无 GUI 资源核验不作为真实焦点证据。
